# 영상 수집 기준 v2 — 위닝 프로덕트 발굴 기준서

> 목적: 미국·영어권 숏폼에서 **한국 유통(소싱/수입 판매)으로 가져올 수 있는 위닝 프로덕트**를 조기에 찾는다.
> v1의 문제: 기준이 "제품"이 아니라 "판매자 계정"을 걸러내는 데 맞춰져 있었다. 판매자 링크·영상 75개·자기소개 시그니처를
> **통과 관문(gate)** 으로 쓰면, 이미 판매자가 붙어 포화된(=먹을 게 없는) 제품만 수집된다.
> v2는 **제품 중심 + 속도(velocity) 중심**으로 뒤집고, 판매자 신호는 관문이 아니라 가점으로 강등한다.

---

## 0. 설계 원칙

1. **제품이 주인공인 영상만** — 사람·밈·댄스·일상은 제품이 찍혀 있어도 제외.
2. **절대 조회수보다 속도** — 500만 뷰 6개월 전 영상 < 30만 뷰 5일 전 영상.
3. **수요는 댓글이 증명** — "where can I buy" 류 구매의도 댓글이 최종 근거.
4. **포화 전 구간을 노린다** — 판매자 다수 = 늦음. 수요는 터졌는데 판매자가 0~2명인 구간이 S급.
5. **하드 필터는 싸게, 판단은 점수로** — API 필드로 계산 가능한 것만 관문. 애매한 건 점수화해서 티어로 나눈다.

## Phase 0 — 캘리브레이션 모드 (★ 현재 단계)

> 아래 §2~§4의 정식 임계값은 아직 검증 안 된 추정치다. 정식 기준을 켜기 전에 **기준을 낮춰 대량 수집(회당 150~300건)
> → 운영자가 직접 소싱감/탈락 라벨링 → 라벨 분포로 임계값·배점을 보정**하는 학습 루프를 2~3라운드 돌린다.

### 완화 기준 (정식값 대비)

| 파라미터 | v2 정식 | Phase 0 완화 | 비고 |
|---|---|---|---|
| RECENCY_WINDOW_DAYS | 30 | **60** | 표본 확보 우선 |
| MIN_VIEWS_PER_DAY | 10,000 | **2,000** | 속도 필터는 남기되 문턱만 낮춤 |
| MIN_VIEW_COUNT | 30,000 | **10,000** | |
| MIN_LIKE_RATE | 3% | **1%** | 어뷰징 컷 정도만 |
| 제품 노출(H5) | 필수 | **유지** | 밈/댄스가 섞이면 평가 자체가 오염됨 |
| 언어/시장(H6) | 필수 | **유지** | 영어권 타게팅은 실험 대상 아님 |
| 스코어 컷(45점 미만 탈락) | 적용 | **폐지 — 전부 저장** | 단, 점수·티어는 계산해서 함께 저장 (모델 정확도 측정용) |
| 빅브랜드/대형물 제외 | 제외 | **플래그만 달고 저장** | "제외가 맞았는지"도 검증 대상 |

쿼터 현실: RapidAPI(인스타)는 월 30회 → 캘리브레이션은 **TikTok(tikwm, 무료) 중심**, 인스타는 라운드당 해시태그 2~3개만.

### 라벨링

- 영상 카드에 관리자용 3단 평가 버튼: **💰 소싱감 / 🤔 애매 / ❌ 탈락**
- DB: `Video.userVerdict` (WINNER / MAYBE / REJECT, null=미평가) — 필드 1개 추가
- 기존 숨김/삭제 버튼과 별개 (숨김 = 노출 제어, 평가 = 학습 데이터)

### 학습 루프

1. 완화 기준으로 수집 (~200건), 각 영상에 v2 점수·티어를 **미리 계산해 저장** (게이트로는 안 씀)
2. 운영자 라벨링 (라운드당 최소 100건 목표)
3. 보정 분석: 💰 vs ❌ 그룹의 viewsPerDay / 좋아요율 / 공유율 / intentRate / 카테고리 / 가격대 분포 비교
   → 💰 집중 구간으로 임계값·배점 조정 + "v2 점수가 💰를 얼마나 맞혔나"로 모델 자체 검증
4. 2~3라운드 반복 후 정식값 확정 → 완화 파라미터 폐기, 정식 기준 전환

|---|---|

## 2. 하드 필터 (전부 통과해야 다음 단계로. API 필드만으로 계산)

| # | 필터 | 기준값 | 이유 |
|---|---|---|---|
| H1 | 최신성 | 업로드 **30일 이내** (v1: 45일) | 위닝 프로덕트는 수명 짧음. 45일이면 이미 포화 |
| H2 | 조회 속도 | **viewsPerDay ≥ 10,000** (= viewCount ÷ 경과일수) | 절대치 2만 뷰 관문 대체. 속도가 트렌드의 본질 |
| H3 | 최소 조회수 | viewCount ≥ 30,000 | 노이즈 컷 (업로드 1일차 과대평가 방지, H2와 AND) |
| H4 | 참여율 | likeCount ÷ viewCount ≥ **3%** | 뷰 어뷰징/광고 도달빨 걸러냄 |
| H5 | 제품 노출 | 영상의 주 피사체가 **물리적 제품** (Gemini vision 판정) | 서비스·앱·강의·밈 컷 |
| H6 | 언어/시장 | §1 기준 통과 | |

> H2 예시: 5일 전 업로드 30만 뷰 → 60,000/day ✅ / 40일 전 200만 뷰 → 애초에 H1 컷.

## 3. 제외 기준 (하드 필터와 별개로 즉시 탈락)

- **밈/댄스/일상/브이로그/스킷** — 제품이 소품으로만 등장
- **빅브랜드 제품** (Apple, Samsung, Nike, Dyson, Stanley 등) — 유통 마진 구조상 소싱 불가
- **라이선스/IP 상품** (디즈니, 산리오, 스포츠팀 등) — 정품 소싱 리스크
- **식품·건강기능식품·화장품 중 성분 이슈** — 국내 수입 시 식약처 인허가 장벽 → *제외가 아니라 `REGULATED` 플래그로 표기* (아래 §7)
- **대형/중량물** (가구, 대형가전) — 물류비로 마진 붕괴
- **디지털 상품/서비스/구독**
- 기존 제외 패턴(인도권 문자, 얼굴 위주 콘텐츠 등)은 유지

## 4. 스코어링 모델 (하드 필터 통과분에 100점 만점, 티어 판정)

### A. 수요 신호 — 35점 (댓글 샘플 상위 30개 기준)

| 신호 | 배점 |
|---|---|
| 구매의도 댓글 비율(intentRate) ≥ 25% | 15 |
| intentRate 10~25% | 8 |
| **구매확정 표현** 존재 ("just ordered", "bought one", "mine arrived") — 의도보다 강한 신호 | +10 |
| "link?"/"where to buy" 류 직접 질문 ≥ 3건 | +10 |

구매의도 정규식(영어 강화):
`where (can|do) i (buy|get)`, `link( please)?`, `need this`, `take my money`, `adding to cart`,
`just ordered`, `bought (one|it|this)`, `on its way`, `drop the link`, `i need the link`

### B. 확산 속도 — 25점

| 신호 | 배점 |
|---|---|
| viewsPerDay ≥ 100,000 | 15 |
| viewsPerDay 30,000~100,000 | 10 |
| viewsPerDay 10,000~30,000 | 5 |
| 공유율 shareCount ÷ viewCount ≥ 0.5% (공유 = 제품 자체의 바이럴성) | +10 |

### C. 제품성 (Gemini 판정) — 25점

| 신호 | 배점 |
|---|---|
| **문제해결형 or Wow-factor형** (before/after, "왜 이걸 이제 알았지" 반응 구조) | 12 |
| 소형·경량 (개인 항공/해상 소량 수입 가능해 보임) | 7 |
| 추정 소비자가 $10~$60 구간 (충동구매 가격대 + 유통 마진 확보) | 6 |

### D. 시장 검증 — 15점 (관문 아님, 가점)

| 신호 | 배점 |
|---|---|
| 동일 제품을 **2개 이상 다른 계정**이 올림 (해시태그/제품명 매칭) | 8 |
| TikTok Shop 태그 or bio 판매 링크 존재 — "팔리는 물건" 증명 | 7 |
| ⚠️ 동일 제품 게시 계정 **10개 이상** → 포화 신호, D점수 0점 처리 + `SATURATED` 플래그 | −(D 전체) |

### 티어 판정

| 티어 | 점수 | 의미 / 액션 |
|---|---|---|
| **S** | 75+ | 즉시 소싱 검토 대상. 대시보드 최상단 |
| **A** | 60~74 | 워치리스트 — 3~5일 후 재수집해 velocity 재측정 |
| **B** | 45~59 | 참고용 수집 (카테고리 트렌드 파악) |
| 탈락 | <45 | 저장 안 함 |

## 5. v1 판매자 관문의 처리 (핵심 변경)

| v1 (관문) | v2 |
|---|---|
| bio 판매 링크 없으면 탈락 | **가점 7점**으로 강등 (§4-D). 링크 없어도 수요 신호가 강하면 수집 — 그게 바로 선점 기회 |
| 계정 영상 수 ≥ 75 탈락 | **폐기.** 대형 셀러 편향 = 포화 제품 편향. 오히려 신생 계정의 급발진이 더 좋은 신호 |
| 자기소개 시그니처 정규식 | **폐기** (판매자 판정 자체가 관문이 아니므로 불필요, creator fetch API 호출도 절약됨) |
| intentRate≥30% or DPM≥30 관문 | **점수화** (§4-A). 관문은 하드 필터 6개로 축소 |

## 6. 키워드/해시태그 전략 (수집 쿼리 자체를 구매자 관점으로)

v1은 판매자 관점 키워드(seller phrases, 콘셉트 용어)가 많았다. v2는 **구매자가 모이는 해시태그** 중심:

**핵심 (매 수집마다):**
`tiktokmademebuyit` · `amazonfinds` · `founditonamazon` · `tiktokshopfinds` · `viralproducts` · `musthaves`

**카테고리 로테이션 (수집 회차별 순환 — API 쿼터 절약):**
- 주방: `kitchengadgets` `kitchenfinds` `cookinghacks`
- 청소/수납: `cleaningtok` `cleaninghacks` `homeorganization`
- 차량: `caraccessories` `cargadgets`
- 반려동물: `petgadgets` `petmusthaves`
- 뷰티툴(성분 무관 기기류): `beautygadgets` `hairtools`
- 홈/조명: `homefinds` `roomdecor` `ledlights`

**계절 슬롯 (분기별 교체, 1~2개):** 여름 `coolinggadgets` `beachessentials` / 겨울 `wintergadgets` `heatedproducts` 등

## 7. 저장 시 플래그 (제외하지 않고 표기만)

| 플래그 | 조건 | 이유 |
|---|---|---|
| `REGULATED` | 전자제품(KC/전파인증), 화장품, 유아용품, 식품 접촉 제품 | 소싱 가능하지만 인증 비용/기간 고려 필요 |
| `SATURATED` | 동일 제품 게시 계정 10개+ | 늦었지만 카테고리 참고 가치는 있음 |
| `RISING` | A티어 중 재수집 시 viewsPerDay 상승 | 워치리스트 승격 후보 |

## 10. v1 → v2 한 줄 요약

**"판매 링크 있는 대형 셀러의 2만뷰+ 영상"** 을 모으던 것에서 →
**"영어권에서 지금 막 뜨고 있고(속도), 사고 싶다는 댓글이 달리는(수요), 소싱 가능한 소형 제품(제품성)"** 을 점수로 줄 세워 모으는 것으로 변경.
판매자 존재는 검증 가점일 뿐, 판매자가 아직 없는 고수요 제품이 최상급 매물이다.
